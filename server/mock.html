Coding exercise

Write a function merge_intervals(intervals) that takes a list of closed intervals [start, end] and returns the list with all overlapping intervals merged, sorted by start.

Input:  [[1,3],[2,6],[8,10],[15,18]]
Output: [[1,6],[8,10],[15,18]]

Input:  [[1,4],[4,5]]
Output: [[1,5]]

Discuss time and space complexity. Python preferred.
